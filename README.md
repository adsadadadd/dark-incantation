# Плагины сервера (Paper 1.21.11)

Автор: x1no4ekk. Java 21, Maven, MySQL (HikariCP).

| Плагин | Папка | Описание |
|---|---|---|
| Core | [`Core/`](Core/) | Ядро сервера: пользователи, хомы через Рог телепортации, команды, киты, варпы, чат |
| Economy | `Economy/` | Валюта «АРЫ», Vault-провайдер, обмен алмазной руды (шаг 3) |
| Guilds | `Guilds/` | Гильдии, казна, хранилище, меню, PlaceholderAPI, голограммы (шаг 4) |

Каждый плагин собирается отдельно: `mvn clean package` в его папке.
